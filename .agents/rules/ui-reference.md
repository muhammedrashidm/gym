# UI Implementation Rules

Whenever you are tasked with creating or modifying a UI page in the Flutter app or React app:
1. You MUST consult the `stitch_screens.md` file located in the root directory (`c:\Desk\gym_all\stitch_screens.md`).
2. Search for a matching screen in that file. If a match is found, refer to its design/PRD/Stitch code before proceeding.
3. If no matching page is found in `stitch_screens.md` for the requested UI, you MUST explicitly ask the user to provide one or generate one via Stitch MCP before writing any code.
